# OKOMALL

Salon & beauty booking website — find salons, compare prices, pick a professional and a time, and book in under a minute.

Static site (HTML, CSS, vanilla JS). No build step.

## Features
- Search and filter salons, live availability, map pins
- Salon detail page with services, team, reviews, similar salons
- 4-step booking flow with offers applied automatically
- Log in / Sign up (demo OTP `1234`), saved salons, My appointments, reschedule and cancel
- Offers, FAQ, mobile app section

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.
